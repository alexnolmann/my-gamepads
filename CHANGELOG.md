# Changelog

## 1.0.0 — 2026-10-25

- Мост для Wireless Controller 054C:05C4 / 054C:09CC: USB и Bluetooth, до четырёх виртуальных Xbox 360.
- Автоматическое назначение кнопок, мёртвая зона 8%, переподключение и очистка виртуальных устройств.
- Интерфейс WinForms с DPI-масштабированием и живыми карточками геймпадов.
- Собственная иконка геймпада для EXE, окна, панели задач и трея.
- Кнопка установки оригинального ViGEmBus Setup 1.22.0 из встроенного ресурса; контроль SHA-256 и обработка UAC/перезагрузки.
- Один автономный Windows x64 EXE со встроенным .NET; журналы в LocalAppData.
- Лицензия MIT, уведомления сторонних компонентов, сценарий сборки и архивы для публикации.
