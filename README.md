# Мои геймпады / MyGamepads

Небольшое приложение для Windows, которое автоматически подключает совместимые Wireless Controller к играм как отдельные Xbox 360. Профили и ручное назначение кнопок не нужны. До четырёх геймпадов одновременно.

**Проверены два конкретных нонейм-геймпада: оба по USB, USB + Bluetooth и оба по Bluetooth. Последний вариант проверен пользователем в игре. Другие экземпляры с теми же идентификаторами требуют проверки.**

## Готовая версия

После сборки файлы для публикации находятся в `dist/`:

- `MyGamepads-1.0.0-win-x64.zip` — готовое приложение с документацией и лицензиями.
- `MyGamepads-1.0.0-win-x64/MyGamepads.exe` — один автономный EXE со встроенным установщиком ViGEmBus и .NET Runtime.
- `MyGamepads-1.0.0-source.zip` — исходники, сценарий сборки и оригинальный установщик драйвера.
- `SHA256SUMS.txt` — SHA-256 готовых файлов.

Нужна Windows 10/11 **x64**. Основная программа не поддерживает x86 или ARM64, несмотря на мультиархитектурный установщик внутри. Отдельная установка .NET не требуется. Приложение не подписано цифровой подписью; оригинальный установщик драйвера подписан Nefarius.

## Первый запуск

1. Распакуйте архив и откройте `MyGamepads.exe`.
2. Если ViGEmBus отсутствует, нажмите **«Установить драйвер»**, подтвердите запрос Windows и пройдите штатный мастер. Нужны права администратора. Интернет для установки не нужен. Если мастер сообщает о необходимости перезагрузки, сохраните работу и перезагрузите ПК самостоятельно.
3. Подключите геймпады по USB либо предварительно выполните сопряжение Bluetooth в Windows.
4. Дождитесь «Работает» на нужных карточках и запустите игру. Приложение должно оставаться открытым или свёрнутым в трей.

Существующий рабочий драйвер не обновляется автоматически. Кнопка установки открывает официальный установщик; на время его работы приложение отключает свои виртуальные геймпады. Закройте игру перед установкой или восстановлением драйвера. Удаление приложения не удаляет общий системный ViGEmBus.

## Как это работает

`Физический геймпад → HID → MyGamepads → ViGEmBus → виртуальный Xbox 360 → XInput игры`

Это преобразование через системный драйвер. **x360ce не требуется.** Приложение не меняет файлы игры и не устанавливает DLL в её папку. Без ViGEmBus виртуальные Xbox-контроллеры не создаются.

## Совместимость и назначения

Принимаются устройства с VID `054C` и PID `05C4` либо `09CC`, передающие совместимые с DualShock 4 пакеты. Это фильтр модели/протокола, а не серийных номеров. Идентификаторы сами по себе не гарантируют совместимость всех копий.

| Геймпад | Xbox |
| --- | --- |
| Крестик / круг / квадрат / треугольник | A / B / X / Y |
| L1 / R1 | LB / RB |
| L2 / R2 | LT / RT |
| Options / Share | Start / Back |
| Нажатия стиков | L3 / R3 |
| PS | Guide |

Стики и крестовина передаются автоматически. Мёртвая зона стиков — 8%. Вибрация, гироскоп, сенсорная панель, подсветка и показ заряда не реализованы. Автоматического сопряжения Bluetooth и автозагрузки нет.

Игра определяет поддержку локальных игроков и порядок присоединения. Максимум четыре виртуальных Xbox, но фактически проверены два физических геймпада. Смена USB-порта или способа подключения может изменить нумерацию; устойчивые номера по серийному номеру не сохраняются.

## Управление и диагностика

- «Остановить» отключает виртуальные геймпады; «Включить» запускает передачу снова.
- «Свернуть в трей» и сворачивание окна оставляют приложение работающим. Закрытие окна или «Выход» в трее останавливает его.
- «Лицензии» показывает лицензии программы и встроенных компонентов, включая драйвер и .NET.
- Ошибки и диагностические отчёты сохраняются в `%LOCALAPPDATA%\MyGamepads`, а не рядом с EXE. Сетевых запросов приложение не делает. Рантайм .NET и штатный установщик Windows могут создавать собственные временные файлы/системные журналы.

Если игра видит двойной ввод, нет подключения или геймпад «зависает», см. [устранение неполадок](docs/TROUBLESHOOTING.md).

## Сборка и публикация

Нужны Windows x64, PowerShell 7 и .NET SDK **10.0.201** (или более новая исправляющая версия той же ветки). Первая сборка загружает пакеты из NuGet. Драйвер уже лежит в репозитории и проверяется перед сборкой по SHA-256 и Authenticode.

```powershell
pwsh -File scripts/build.ps1
# Дополнительно проверить размеры интерфейса:
pwsh -File scripts/build.ps1 -CheckLayout
```

Установщик драйвера на компьютере сборки **не запускается**. Сценарий проверяет преобразование ввода и безопасные ветви установки через тестовый запускатель. `--check-driver` и `--diagnose` выполняются отдельно на машине с ViGEmBus.

Подробнее: [разработка и тестирование](docs/DEVELOPMENT.md), [подготовка релиза](docs/RELEASING.md), [источник драйвера](drivers/ViGEmBus/manifest.json).

## Структура

```text
src/MyGamepads/   приложение, диагностика и проверки
scripts/         воспроизводимый сценарий сборки и упаковки
drivers/ViGEmBus/ оригинальный установщик, лицензия, манифест
licenses/        лицензии встроенного .NET
docs/            инструкции и ограничения
artifacts/       промежуточные сборки и локальные результаты (не в Git)
dist/            готовые EXE и архивы (не в Git)
```
