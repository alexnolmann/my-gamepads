# Разработка и проверки

## Среда

Windows x64, PowerShell 7, .NET SDK 10.0.201 (global.json разрешает более новую patch-версию этой ветки). В автономную сборку включён .NET Runtime / Windows Desktop Runtime 10.0.5. Версии закреплены в Directory.Build.props; NuGet — в packages.lock.json. Первая сборка требует доступа к NuGet, а проверка подписи драйвера может требовать доступа к цепочке сертификатов Windows.

```powershell
dotnet restore MyGamepads.slnx --locked-mode
dotnet build MyGamepads.slnx -c Release
pwsh -File scripts/build.ps1 -CheckLayout
```

Полный сценарий выпуска создаёт один self-contained EXE. Тримминг отключён: WinForms и клиент с встроенными native-компонентами должны сохранять необходимые метаданные и ресурсы. .NET извлекает native-библиотеки во временный каталог; это ожидаемое поведение single-file, а не требование держать DLL рядом с EXE.

## Исходники

Иконка: `src/MyGamepads/Assets/app.svg`, многоразмерный `app.ico` (16–256 px) и PNG-превью. Для пересоздания ICO/PNG выполните `pwsh -File scripts/New-AppIcon.ps1`. Рисунок создан для проекта и распространяется под MIT.

| Файл | Назначение |

| Program.cs | Точка входа, одна GUI-копия на сеанс, диагностические параметры |
| MainForm.cs | WinForms, масштабирование DPI, карточки, управление установкой |
| Bridge.cs | Обнаружение, сессии HID, отдельный Xbox на устройство, очистка |

| AppPaths.cs | Каталог данных пользователя и перенаправление вывода проверок |
| Diagnostics.cs | Проверки преобразования, HID probe, интеграция XInput |
| DriverSetupTests.cs | Встроенный ресурс, повреждение, отмена, коды выхода, очистка |
| LayoutCheck.cs | Геометрия текста/контролов без подключения геймпадов |

## Безопасные проверки без установки драйвера

```powershell
$exe = '.\dist\MyGamepads-1.0.0-win-x64\MyGamepads.exe'
# WinExe запускайте с ожиданием завершения:
Start-Process $exe -ArgumentList '--self-test' -Wait
Start-Process $exe -ArgumentList '--setup-test' -Wait
Start-Process $exe -ArgumentList '--layout-check' -Wait
```

Результаты: tests.txt, setup-tests.json, layout-check.json в `%LOCALAPPDATA%\MyGamepads`. Для автоматизации добавьте `--output-dir "полный путь к каталогу"`. Код завершения 0 — успех. Сценарий build.ps1 сам направляет вывод в artifacts/validation.

`--self-test`: 27 проверок кнопок, крестовины, диапазонов/знаков осей, USB и Bluetooth CRC. `--setup-test`: 31 проверка встроенного EXE и обработки установки с подменённым запускателем. **Реальный установщик не запускается, драйвер не меняется.** Покрываются успех, перезагрузка 3010/1641, отмена 1602/UAC 1223, повреждённый ресурс и ошибка запуска; временные файлы удаляются.

`--layout-check`: пустое окно, две и четыре карточки на трёх ширинах при фактическом DPI текущего окружения. Проверяет обрезание высоты текста, горизонтальный выход и перекрытие соседних Label/Button. Это геометрическая проверка; она не заменяет визуальную проверку и не симулирует все масштабы мониторов.

## Проверки с ViGEmBus / устройствами

Закройте обычный экземпляр MyGamepads, игры и другие эмуляторы перед аппаратной диагностикой. Не трогайте стики во время сравнения снимков.

- `--check-driver`: создаёт и закрывает соединение клиента с ViGEmBus, без виртуальных контроллеров. Проверяет также загрузку встроенной native-библиотеки из single-file EXE.
- `--probe`: читает по одному пакету с каждого подходящего HID с ограничением времени; сохраняет probe.json.
- `--diagnose`: создаёт два Xbox с различающимися кнопками/осями, проверяет XInput и возврат к нулю, затем читает физические устройства и сравнивает состояния с отдельными XInput-местами. В конце отключает собственные виртуальные контроллеры. При отсутствии физических геймпадов проверяется только виртуальная часть — число реальных устройств смотрите в отчёте.

## Установка драйвера

Только нажатие «Установить драйвер» вызывает `DriverSetup.InstallAsync`. Программа останавливает свою HID/XInput-мостовую часть, извлекает EXE в уникальный подкаталог `%LOCALAPPDATA%\MyGamepads\DriverSetup`, проверяет SHA-256 и запускает `runas` с `/norestart`. Установщик остаётся интерактивным. Автоматической установки при старте или скрытой установки нет. После завершения извлечённый EXE удаляется; штатный установщик может сохранить собственный системный кэш.

Исходный установщик в drivers проверяется сценарием сборки по SHA-256 **и** Authenticode издателя. В runtime проверяется SHA-256 встроенных неизменённых байтов. Изменение версии драйвера требует обновления бинарника, manifest.json, DriverSetup.Sha256/FileName, csproj, документации и лицензий. Не перекомпилируйте и не переподписывайте чужой драйвер как собственный.

## Известные пределы проверки

Исходная аппаратная цепочка проверена с установленным ViGEmBus 1.16.112.0; встроенный Setup 1.22.0 не устанавливался на рабочий ПК в ходе упаковки релиза. Чистая установка/восстановление/перезагрузка требуют отдельной проверки в Windows VM или на тестовом ПК. Успех mock-проверок не является подтверждением установки в чистой системе.
