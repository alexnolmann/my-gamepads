# Подготовка релиза

1. Обновите Version в src/MyGamepads/MyGamepads.csproj и CHANGELOG.md. Обновите номера в пользовательских примерах документации при смене версии.
2. Убедитесь, что оригинальный драйвер совпадает с manifest.json и имеет ожидаемую подпись. Проверьте upstream при любом обновлении зависимости; ViGEmBus больше не развивается.
3. Выполните `pwsh -File scripts/build.ps1 -CheckLayout`. Не пропускайте проверку закреплённых NuGet-зависимостей. Ошибка сети/проверки сертификата при сборке должна быть исправлена, а не скрыта отключением проверки.
4. На отдельной Windows x64 VM без .NET проверьте первый запуск EXE, отсутствие драйвера, отмену UAC, установку через кнопку, повторный запуск и перезагрузку при запросе. Дополнительно проверьте установленный старый драйвер и восстановление. Этот системный сценарий не автоматизирован и ещё не пройден в чистой системе для 1.0.0.
5. Проверьте два реальных контроллера: USB + USB, USB + Bluetooth, Bluetooth + Bluetooth; затем игру с локальным кооперативом. Последний вариант проверен пользователем в исходной аппаратной конфигурации. Проверяйте интерфейс на масштабах Windows 100/125/150/175/200% и при смене монитора; геометрические проверки охватывают только фактический DPI среды запуска.
6. Проверьте состав source ZIP: нет bin/obj, журналов, HID-отчётов, абсолютных пользовательских путей, секретов. По возможности соберите исходный ZIP в другом каталоге, содержащем пробелы.
7. Для публикации загрузите бинарный ZIP, исходный ZIP и SHA256SUMS.txt. Можно распространять и отдельный EXE: основные лицензионные уведомления встроены и доступны через «Лицензии». ZIP предпочтителен, поскольку включает инструкции.

Сценарий не создаёт GitHub-релиз, не загружает файлы и не меняет настройки доступа. Публикация остаётся отдельным действием владельца.

## Подпись

EXE MyGamepads не подписан. Подпись Nefarius относится только к встроенному оригинальному установщику ViGEmBus. Нельзя представлять её как подпись всего приложения. При наличии собственного сертификата подпишите конечный MyGamepads.exe **перед** созданием ZIP и SHA-256, затем пересоздайте архив/контрольные суммы. Не публикуйте приватный ключ или пароль сертификата в репозитории.

## Обновление .NET

В этой сборке runtime закреплён на 10.0.5, SDK — 10.0.201. Перед последующими выпусками проверьте актуальные исправления .NET, обновите Directory.Build.props/global.json и лицензии, пересоздайте packages.lock.json и повторите проверки. Не считайте автономный EXE автоматически обновляемым вместе с установленным на ПК .NET: он содержит свою копию runtime.
