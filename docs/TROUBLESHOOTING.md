# Устранение неполадок

## Приложение не создаёт Xbox-контроллеры

Проверьте строку ViGEmBus в окне. Если драйвер отсутствует, нажмите «Установить драйвер». Само приложение не требует запуска от администратора: повышенные права запрашивает только установщик. Отмена UAC или мастера не считается успешной установкой.

Setup 1.22.0 содержит драйвер **1.21.442.0**: это разные номера компонентов. По [замечанию автора](https://github.com/nefarius/ViGEmBus/releases/tag/v1.22.0), обновление поверх старой версии иногда требует повторного запуска мастера. Если версия драйвера не изменилась, закройте связанные приложения и повторите штатную установку. Не удаляйте вручную файлы из System32. Для уже работающей старой версии обновление не обязательно: приложение проверялось также с 1.16.112.0.

Код 3010 означает, что установке нужна перезагрузка. Программа не перезапускает Windows автоматически. Если после установки подключение не восстановилось, перезагрузите ПК и запустите программу снова.

Драйвер общий для разных приложений. Его установка/восстановление может затронуть DS4Windows, x360ce и другие программы на ViGEmBus. Для удаления используйте штатный список установленных приложений Windows; удаление EXE MyGamepads оставляет драйвер установленным.

## Геймпад обнаружен, но не передаёт ввод

Подключите его непосредственно к USB-порту ПК. На проверенной конфигурации оба устройства были видны через USB-хаб, но переставали отвечать, в том числе с таймаутом Windows 121. Через прямые порты заработали. Это наблюдение конкретной конфигурации, а не запрет всех хабов.

Проверьте кабель с передачей данных, заряд и состояние устройства. При отсутствии пакетов 3 секунды приложение отключает виртуальное устройство и повторяет попытку. После физического переподключения обнаружение обычно занимает около секунды, затем выполняется инициализация виртуального контроллера.

## Bluetooth

Сначала выполните сопряжение в параметрах Windows. Для проверенных геймпадов использовались Share + PS до частого мигания и выбор Wireless Controller. У других копий сочетание может отличаться — ориентируйтесь на их инструкцию. Само приложение не управляет Bluetooth-адаптером.

USB и Bluetooth могут показывать разные PID: на проверенном устройстве это 05C4 и 09CC. Оба разрешены. Беспроводное устройство может объявлять 547-байтный HID-буфер, хотя начальный пакет содержит только короткое состояние 0x01; приложение это учитывает.

## Игра видит двойные нажатия

Закройте x360ce/DS4Windows и другие преобразователи. Если игру запускает Steam и включён Steam Input, проверьте игру с отключённым Steam Input. Если ранее использовалась старая DLL-версия x360ce, проверьте её файлы в папке игры по инструкции x360ce: MyGamepads автоматически их не изменяет.

MyGamepads сначала пытается получить эксклюзивный доступ, затем переходит на общий. Это не эквивалент системного скрытия физического устройства. Состояние доступа доступно в подсказке при наведении на USB/Bluetooth. Фильтр HidHide здесь не устанавливается. Игры, одновременно читающие DirectInput и XInput, могут видеть исходное и виртуальное устройство.

## Второй игрок не присоединяется

У каждого геймпада должен быть статус «Работает». Подключите их до запуска игры. Дальнейший выбор игроков и поддержка локального кооператива зависят от самой игры. Другие Xbox-контроллеры и эмуляторы занимают общий лимит XInput в четыре места.

## Журналы

Откройте `%LOCALAPPDATA%\MyGamepads`. Файл `controller.log` ротируется после 1 МБ (сохраняется одна копия `.old`). В нём могут быть локальные пути и сообщения Windows. Отчёт `probe.json` может содержать HID-пути/идентификаторы устройств; проверяйте и удаляйте персональные сведения перед публичной отправкой. Никакие журналы автоматически не отправляются.

Если EXE не запускается или Windows сообщает о несовместимости, проверьте архитектуру x64 и поддерживаемую версию ОС. Приложение не имеет цифровой подписи. При распространении сверяйте SHA-256 и получайте релиз из доверенного источника; инструкции по обходу защит Windows в проект не входят.
